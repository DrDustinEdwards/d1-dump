# Security policy

## Reporting a vulnerability

Report it privately. Do not open a public issue or pull request for it.

- Use GitHub's private vulnerability reporting: the **Report a vulnerability** button on this repository's **Security** tab.
- Or email security@dustinedwards.info.

You will get an answer within a few days. Please include what you found, how to reproduce it and which version or commit it affects.

## Supported versions

Only the latest release, or the latest commit on the default branch, gets fixes.
